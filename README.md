# 咖啡店营业看板

一个网页看板，读取 Google Sheet 里的咖啡店销售记录，显示：

- 营业额、售出数量、平均每天营业额、卖得最好的品项
- 品项排行（按营业额从高到低，含数量和占比）
- 每日营业额柱状图
- 时间范围切换：今天 / 最近 7 天 / 本月 / 全部

## 怎么用

`coffee-dashboard.html` 是一个 Claude Artifact 页面，需要在 claude.ai 里打开，通过你自己连接的 Google Drive 读取表格（每分钟自动同步）。直接在浏览器里打开这个文件不能读取数据。

## 表格格式

第一个工作表的第一行是表头，之后每卖一笔加一行：

| Timestamp | Item | Quantity | Price |
|---|---|---|---|
| 2026-10-01 9:10 | Latte | 2 | 9.5 |

- `Price` 是**单价**，金额 = Quantity × Price
- 表头也可以用中文：日期 / 品项 / 数量 / 单价
- 格式不对的行不计入，页面底部会提示有几行

要换成另一份表格，修改 `coffee-dashboard.html` 里的 `FILE_ID`。
